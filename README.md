# E-Commerce Backend – Effort Outdoor

Backend ini merupakan bagian dari sistem e-commerce **Effort Outdoor** yang
dikembangkan dengan arsitektur **frontend dan backend terpisah**.

---

## 📌 Deskripsi
Repository ini berisi **backend** sistem e-commerce berbasis web yang
bertanggung jawab dalam pengolahan data, logika bisnis, pengelolaan pesanan,
serta komunikasi dengan database.

Backend ini digunakan oleh aplikasi frontend e-commerce yang berada pada
repository terpisah dan dikembangkan sebagai bagian dari **proyek tugas kuliah**.

---

## 🎯 Tujuan Proyek
- Menyediakan layanan backend untuk sistem e-commerce  
- Mengelola data produk, pengguna, dan transaksi  
- Menangani alur pemesanan dan status pesanan  
- Menyediakan API untuk kebutuhan aplikasi frontend  

---

## ⚙️ Fitur Utama
- Manajemen data produk  
- Manajemen data pengguna  
- Proses transaksi dan pemesanan  
- Pengelolaan status pesanan  
  (belum dibayar, dikemas, dikirim, selesai)
- Pengelolaan pengeluaran bisnis
- Analitik dan CRM sederhana  
- API backend untuk integrasi frontend  
- Dukungan dashboard admin dan laporan  

---

## 🛠️ Teknologi yang Digunakan
- **PHP**  
- **MySQL**  
- **REST API**  

---

## 🚀 Cara Menjalankan Aplikasi
1. Clone repository backend ini  
2. Import database MySQL yang digunakan  
3. Konfigurasikan koneksi database pada file konfigurasi  
4. Jalankan server lokal seperti XAMPP  
5. Hubungkan frontend ke endpoint API backend 

---

## 🧩 Arsitektur Sistem
Sistem e-commerce Effort Outdoor menggunakan arsitektur
**frontend–backend terpisah**, di mana:
- Backend berperan sebagai pengelola logika bisnis dan API  
- Frontend berperan sebagai antarmuka pengguna
